# Security

## Consent and Privacy
- This app requires explicit user consent before performing any accessibility-related actions.
- Accessibility permissions are granted solely through system settings by the user.
- The app does not perform covert monitoring or record user activity without knowledge.

## Data Handling
- The app performs no clicks, gestures, text entry, screenshots, or network transmission.
- No user data is collected, stored, or transmitted externally.

## Remote-Control Security
- No remote control or remote command execution is implemented or allowed.
- The app operates entirely locally on the device.

## Transparency
- The app clearly discloses its use of Accessibility features on the home screen.
- Users are informed that accessibility access must be explicitly granted in system settings.
